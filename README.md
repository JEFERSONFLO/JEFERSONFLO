## 🚍 Proyecto destacado

### Sistema de reservas y gestión de transporte

Plataforma web y móvil diseñada para administrar las operaciones de empresas de transporte.

### Funcionalidades principales

* Gestión de rutas, buses y conductores.
* Configuración de horarios y disponibilidad.
* Selección y reserva de asientos.
* Gestión de clientes y pasajeros.
* Administración de encomiendas.
* Control de usuarios, roles y permisos.
* Autenticación y manejo de sesiones.
* Notificaciones mediante Firebase.
* Panel administrativo para el control de operaciones.
* Integración entre frontend, aplicación móvil, backend y base de datos.

### Tecnologías utilizadas

`React` · `React Native` · `Expo` · `NestJS` · `TypeScript` · `PostgreSQL` · `Prisma` · `Firebase`
